# Roteiro de Evolução (Roadmap) — Amanhecer 2.0

## Versão 2.0 (Versão Atual Implementada)
- [x] PWA instalável com suporte Android, iOS e Desktop.
- [x] Onboarding intuitivo em 3 etapas com prévia real do tamanho de fonte (16px a 32px).
- [x] Leitura devocional completa: Texto bíblico, reflexão (250-500 palavras), aplicação prática, oração sugerida e recomendação musical verificada.
- [x] Motor do Versículo do Dia determinístico e reproduzível por data.
- [x] Sistema de IA com Gemini Escritor e Gemini Revisor em papéis separados.
- [x] Auditoria automatizada nos 8 critérios teológicos com nota de corte mínima de 90/100.
- [x] Recálculo determinístico sem confiar na nota cega da IA.
- [x] Validação determinística sem IA (cânon de 66 livros, capítulos, versículos, catálogo musical).
- [x] Painel de Auditoria Teológica visual com simulador de critérios interativo.
- [x] Diário Pessoal de oração e reflexão persistido exclusivamente em IndexedDB com exportação e importação JSON.
- [x] Histórico de mensagens anteriores e sistema de favoritos offline.
- [x] Infraestrutura Web Push com envio matinal às 06:06 e lembretes com interrupção após leitura confirmada.
- [x] Workflows de automação do GitHub Actions e deploy na Vercel com cabeçalhos de segurança.
